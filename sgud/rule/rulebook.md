# 規則帳本(w-web-task)

本檔為套件設計與開發階段之規則帳本,為要求程式碼須長成什麼樣,或由規格產出之測試(項目/說明/流程)有哪些,包含軸、單一擁有者、已知限制、破壞性變更紀錄,以及對應是哪些測試檔案或指令等,由agent自行編列、擴充與維護.

體例: 以「規則」為單位, 每條列 站點全集 / 判準(已套 / 未套 / 刻意不套) / 可重跑之盤點指令. 決策緣由指向 `spec/設計要點與取捨.md`(D / L 編號); 處理流程見 `sgud/proc/process.md`; 事件與教訓見 `sgud/exp/experience.md`. 盤點指令以專案根為 cwd. **`git grep` 不搜未追蹤之檔**(`test/tools/` 於 2026-09-28 自 `test/` 頂層搬入, 提交前即是), 該類改以 `grep -n <檔>` 或 Grep 工具查. 行號為 2026-09-29 之值, 改碼後以盤點指令重取.
